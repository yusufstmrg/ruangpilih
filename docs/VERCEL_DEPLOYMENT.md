# Vercel Deployment

The package is designed as a static Vercel-ready frontend.

## Recommended steps
1. Create/import a Vercel project from this folder.
2. Framework: Other / Static Site.
3. Build command: none.
4. Output directory: `.`
5. Set the production domain.
6. Enable HTTPS and review security headers from `vercel.json`.
7. Add analytics after the domain is live.

## Important
This package is the frontend MVP. CMS, affiliate IDs, analytics, legal content and AI backend still need production configuration before commercial launch.
