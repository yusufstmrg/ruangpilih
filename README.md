# RuangPilih — Production Package

Public promise: **Helping You Choose with Confidence**

Internal north star: **Indonesia's Most Trusted Recommendation Platform**

## What is included
- Responsive recommendation-platform frontend
- Premium RuangPilih black/white/gold design system
- Search and trending query interaction
- Category filtering
- Smart Picks recommendation catalog
- Save/bookmark state via localStorage
- Product detail modal
- Compare up to 4 products
- Buying guides preview
- AI Assistant preview state
- Trust / methodology section
- SEO-ready metadata and mobile-first layout

## Current production assumptions
- Affiliate URLs and merchant IDs are placeholders because no live IDs were provided yet.
- Product catalog shown is demonstration data and should be replaced by CMS/merchant feed data before commercial launch.
- AI assistant is a UI prototype only; backend model + structured product graph are not connected yet.
- Legal/entity/contact/social values remain to be finalized.

## Vercel
This project is static and can be deployed directly to Vercel. Recommended production flow:
1. Import project into Vercel or run the Vercel deployment tool.
2. Set final domain and redirects.
3. Replace demonstration content with CMS-backed data.
4. Add analytics and affiliate tracking.
5. Add final legal pages.
